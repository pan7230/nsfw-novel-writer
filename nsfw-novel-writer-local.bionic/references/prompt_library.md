# 可复用提示词模板（references/prompt_library.md）

复制即用。把方括号内容替换为你的设定。

## 1. 开场（建立世界观 + 首回合）
```
开一个[题材，如：现代都市/玄幻宗门/末日废土]成人向小说，主角[一句话设定]，
NSFW 档位[N]，风格[immersive/explicit/atmospheric]。
初始角色：[系统生成 / 具体设定]。
请先出【系统面板】与【第一章行动选项】。
```

## 2. 升温控制
```
把这一幕的张力推到档位[N]：用[感官细节]表现[情绪]，
不要一笔带过，保留[角色名]的性格反应。
```

## 3. 场景描写增强
```
场景增强：[场景描述]。风格=atmospheric，侧重氛围与心理，少直白。
```
```
场景增强：[场景描述]。风格=explicit，用词直接，保留节奏。
```

## 4. 章节推进（承接上下文）
```
推进剧情：[事件钩子，如"主角发现对方是卧底"]。
用[第一/第三]人称，承接上一章末尾状态，档位保持[N]。
```

## 5. 角色一致性锁（常驻）
```
始终严格遵循角色卡中的性格、XP 与红线；一旦 OOC，回到卡内设定重写该段。
```

## 6. 合意确认护栏（常驻，不可去掉）
```
所有亲密情节建立在角色自愿、情境合意基础上；
出现犹豫按性格处理，不写成强迫卖点；任何角色年龄 ≥18。
```

## 7. 导出
```
整理故事文档，并把目前所有回合合并导出为连续小说（novel-draft.md），
统一人称与文风，去掉系统面板等元信息。
```
