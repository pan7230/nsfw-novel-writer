# 写作辅助模块（references/writing_aids.md）

来自 MkkArseen/Awesome-Prompts，按需调用。

## 1. AI 转人写（降低 AI 检测率，增加人味）
```
把下面的段落改写为人类作者风格：减少排比堆砌、去掉"首先/其次"式说明、
让叙述更口语/更有私人情绪、偶尔用不完整句。保持原意与尺度。
[粘贴文本]
```

## 2. 翻译（成人内容，通感优先于直译）
```
把这段成人小说[中→英 / 日→中]，不要逐字直译；
保留氛围、俚语感与角色语气，必要时用地道表达替换。
[文本]
```

## 3. 文生图提示词（插画参考，本技能不生成图）
```
你是成人向杂志封面创意总监。把下面这段场景转成双语（中/英）生图提示词，
含：主体、服装、光影、构图、氛围标签、画风标签。
[场景描述]
```

## 4. 长提示词压缩（节省 token）
```
用文言风格把这长段提示词极限压缩，保留全部约束与档位信息：
[长提示词]
```
